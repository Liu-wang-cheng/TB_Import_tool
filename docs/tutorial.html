准备工作

1 启动程序

双击 智能缺陷管理平台.exe 启动程序。首次启动后，直接在界面上填写配置即可，所有设置会自动保存。

无需额外安装：程序是独立 exe，不需要安装 Python 或其他依赖。所有配置在界面填写后自动保存到 configs/ 目录，下次打开自动加载。

操作步骤

1 填写源平台配置（禅道）

在界面上方的 「禅道配置」 区域，填写三项信息：

字段填什么示例
服务器地址你们公司禅道的网址（到 /zentao 为止）https://zentao.company.com/zentao
账号你登录禅道的用户名zhangsan
密码你登录禅道的密码••••••

如果你们用 Jira，把 「源平台」 下拉框切换到「Jira」，界面会自动切换为 Jira 的配置项。

禅道配置
服务器地址: https://zentao.company.com/zentao
账号: zhangsan 密码: ••••••

✓ 绿色边框 = 已填写

快捷方式：直接从浏览器复制禅道的 Bug 列表页地址，粘贴到「禅道Bug页面地址」输入框，点「解析」按钮，会自动填入产品ID和模块信息。

填写完配置后，先点「连接测试」按钮，确认能连上禅道和 Teambition：

3 设置筛选条件

在「筛选条件」区域选择你要同步哪些 Bug：

筛选项说明建议
产品ID禅道中的产品编号从URL解析或手动填入
项目名称禅道项目名称（如 HS341）可留空，不限制
状态Bug 状态筛选活跃+已确认 最常用
指派人按处理人筛选点「添加」输入姓名，如"IOT-陈斌"
日期筛选按时间段筛选选「全部」不限制日期
小技巧：最简单的筛选方式 — 只填产品ID + 状态选「活跃+已确认」，就能获取当前未处理的所有 Bug。

其他功能说明

「配置」按钮

点击界面底部的「配置」按钮，打开高级配置对话框。可以编辑：

  • Teambition 凭证 — app_id、app_secret、org_id 等应用信息
  • 同步规则 — 去重阈值、标题格式、附件大小限制等
  • 分类器 — TF-IDF 相似度阈值、LLM 大模型配置
  • 钉钉通知 — Webhook 地址、消息模板

这些配置一般由管理员设置好后通过配置文件分发，普通用户不需要修改。

URL 自动解析

在浏览器打开禅道的 Bug 列表页，复制地址栏的 URL，粘贴到「禅道Bug页面地址」输入框：

禅道Bug页面地址: https://zentao.company.com/zentao/bug-browse-11--byModule-122.html 解析

→ 自动填入 产品ID=11, 模块ID=122

自动更新

工具启动时会自动检测新版本。如果发现新版本，会弹出提示框：

发现新版本 v1.4
更新内容：修复分类器精度问题、新增导出功能
当前版本：v1.3
立即更新 跳过

平台切换

在界面顶部「源平台」下拉框可以切换禅道/Jira。切换后：

  • 配置区域自动变为对应平台的输入项
  • 之前填写的禅道配置会保留，切回来还在
  • 筛选条件独立保存，互不影响

常见问题

Q: 连接测试失败怎么办？

A: 按顺序检查：

  1. 服务器地址是否正确 — 不要有空格、末尾不要加斜杠
  2. 账号密码是否正确 — 用浏览器登录禅道确认
  3. 网络是否通畅 — 在浏览器里能否打开禅道页面
  4. 公司 VPN — 如果禅道在内网，先连 VPN

Q: 同步后 Bug 没有出现在 TB 里？

A: 检查日志区：

  • 如果显示「跳过-重复」— 说明这条 Bug 之前已经同步过了，不会重复创建
  • 如果显示「失败」— 查看错误信息，通常是 TB 权限或配置问题

Q: 指派人怎么填写？

A: 点击「添加」按钮，输入禅道中的指派人名称。格式和禅道一致，例如：

  • IOT-陈斌 — IOT 部门的陈斌
  • 算法-张三 — 算法部门的张三
  • 多个指派人就添加多条，支持勾选/取消勾选

Q: 配置填错了想重新来？

A: 点「配置」按钮可以修改所有配置项。界面上的配置修改后会自动保存到配置文件，下次打开不用重新填。

Q: 同步过的 Bug 禅道那边能看到吗？

A: 可以。同步后工具会自动在禅道 Bug 标题前加上 【VLNS-xxxxx】 标签（TB的任务编号），方便在两个平台之间对应查找。
